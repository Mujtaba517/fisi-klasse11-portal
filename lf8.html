🗄️ Lernfeld 8: Daten systemübergreifend bereitstellen

انتقال و فراهم‌سازی امن داده‌ها بین سیستم‌ها

این Lernfeld چیست؟

یاد می‌گیری چطور داده‌ها را بین سیستم‌های مختلف (پایگاه داده، API، فایل، سرویس) به صورت امن و ساخت‌یافته منتقل و در دسترس قرار بدهی.

موضوعات کلیدی

  • مدل‌سازی داده با ER-Modell
  • پایگاه داده رابطه‌ای و SQL
  • API و Webservices (REST)
  • فرمت‌های داده: JSON, XML, CSV
  • یکپارچه‌سازی و تبادل داده بین سیستم‌ها

مراحل مدل‌سازی داده

  1. Konzeptuell – ER-Diagramm (Entity, Attribute, Beziehung)
  2. Logisch – تبدیل به جداول رابطه‌ای + Normalization
  3. Physisch – پیاده‌سازی در MySQL / PostgreSQL

تمرین‌های عملی

✏️ تمرین ۱ – ER-Modell

برای یک سیستم تیکت ساده (User, Ticket, Category, Comment) یک ER-Diagramm بکش و روابط را مشخص کن (1:n یا n:m).

✏️ تمرین ۲ – SQL

جداول را بساز و یک Query بنویس که تمام تیکت‌های باز یک کاربر خاص را همراه با نام دسته‌بندی نشان دهد (JOIN).

✏️ تمرین ۳ – API

یک API ساده (با Python Flask یا Node.js) بنویس که لیست تیکت‌ها را به صورت JSON برگرداند. آن را با curl یا Postman تست کن.

اصطلاحات مهم آلمانی

  • Datenmodellierung – مدل‌سازی داده
  • Entität / Attribut – موجودیت / ویژگی
  • Beziehung – رابطه
  • Schnittstelle (API) – رابط برنامه‌نویسی
  • Datenbereitstellung – فراهم‌سازی داده
  • Normalisierung – نرمال‌سازی
