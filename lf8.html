🗄️ Daten systemübergreifend bereitstellen

96 Std. · Anwendungsentwicklung und Programmierung

🎯 هدف یادگیری

دانش‌آموزان صلاحیت گردآوری داده از منابع غیرمتمرکز، آماده‌سازی و در اختیار قرار دادن آن‌ها را دارند.

📚 چه چیزهایی یاد می‌گیری؟

  • شناسایی و تحلیل منابع داده (ساختار، دسترسی، چارچوب حقوقی)
  • انتخاب منابع ناهمگون برای سفارش مشتری
  • طراحی مفهوم فراهم‌سازی با رعایت امنیت اطلاعات
  • پیاده‌سازی تیمی و تحویل همراه با مستند کاربری

🧩 منابع داده

  • پایگاه داده رابطه‌ای (MySQL, PostgreSQL)
  • فایل‌ها (CSV, JSON, XML)
  • API و Webservices
  • سیستم‌های سازمانی و IoT

🔐 امنیت اطلاعات

  • حداقل داده لازم (Datenminimierung)
  • حداقل دسترسی (Least Privilege)
  • انتقال امن (HTTPS / VPN)
  • رعایت حفاظت از داده شخصی (DSGVO)

✏️ تمرین‌ها

تمرین ۱

سه منبع (MySQL، CSV، API) را از نظر ساختار، دسترسی و ریسک امنیتی مقایسه کن.

تمرین ۲

برای سیستم تیکت ER-Modell بکش و یک Query با JOIN بنویس.

تمرین ۳

یک API ساده JSON بساز و مستند کن.

تمرین ۴

راهنمای کاربری کوتاه برای همان API بنویس.

📖 اصطلاحات

  • Datenquelle – منبع داده
  • Informationssicherheit – امنیت اطلاعات
  • Bereitstellung – فراهم‌سازی
  • Rechtliche Rahmenbedingungen – چارچوب حقوقی

🎯 Zielformulierung

Die Schülerinnen und Schüler besitzen die Kompetenz, Daten aus dezentralen Quellen zusammenzuführen, aufzubereiten und zur weiteren Nutzung bereitzustellen.

📚 Was du lernst

  • Datenquellen ermitteln und analysieren (Struktur, Zugriff, Recht)
  • Heterogene Quellen für den Kundenauftrag auswählen
  • Bereitstellungskonzept unter Informationssicherheit entwickeln
  • Arbeitsteilig implementieren und mit Dokumentation übergeben

🧩 Datenquellen

  • Relationale Datenbanken
  • Dateien (CSV, JSON, XML)
  • APIs und Webservices
  • Fachsysteme und IoT

🔐 Informationssicherheit

  • Datenminimierung
  • Least Privilege
  • Sichere Übertragung
  • DSGVO beachten

✏️ Übungen

Übung 1

Vergleiche drei Quellen (MySQL, CSV, API) nach Struktur, Zugriff und Sicherheitsrisiko.

Übung 2

Erstelle ein ER-Modell für ein Ticketsystem und eine JOIN-Abfrage.

Übung 3

Baue eine einfache JSON-API und dokumentiere sie.

Übung 4

Schreibe eine kurze Benutzeranleitung für die API.

📖 Wichtige Begriffe

  • Datenquelle
  • Informationssicherheit
  • Bereitstellung
  • Rechtliche Rahmenbedingungen

🎯 Learning Goal

Students can merge data from decentralized sources, prepare it and make it available for further use.

📚 What you learn

  • Identify and analyse data sources (structure, access, legal framework)
  • Select heterogeneous sources for a customer order
  • Design a provision concept with information security in mind
  • Implement collaboratively and hand over with user documentation

🧩 Data sources

  • Relational databases
  • Files (CSV, JSON, XML)
  • APIs and web services
  • Business systems and IoT

🔐 Information security

  • Data minimisation
  • Least privilege
  • Secure transfer
  • Respect privacy rules (GDPR)

✏️ Exercises

Exercise 1

Compare three sources (MySQL, CSV, API) by structure, access and security risk.

Exercise 2

Design an ER model for a ticket system and write a JOIN query.

Exercise 3

Build a simple JSON API and document it.

Exercise 4

Write a short user guide for that API.

📖 Key Terms

  • Data source
  • Information security
  • Data provision
  • Legal framework
