🗄️ Lernfeld 8: Daten systemübergreifend bereitstellen

96 Unterrichtsstunden · Anwendungsentwicklung und Programmierung

🎯 Zielformulierung (هدف رسمی Lehrplan)

Die Schülerinnen und Schüler besitzen die Kompetenz, Daten aus dezentralen Quellen zusammenzuführen, aufzubereiten und zur weiteren Nutzung zur Verfügung zu stellen.

فارسی: دانش‌آموزان صلاحیت گردآوری داده از منابع غیرمتمرکز، آماده‌سازی و در اختیار قرار دادن آن‌ها برای استفاده بعدی را دارند.

English: Students can merge data from decentralized sources, prepare it and make it available for further use.

📚 چه چیزهایی یاد می‌گیری؟ (طبق Lehrplan)

  • شناسایی Datenquellen برای سفارش مشتری
  • تحلیل ساختار داده، شرایط حقوقی، امکان و سازوکار دسترسی
  • انتخاب منابع داده heterogen (متنوع و ناهمگون)
  • طراحی مفهوم فراهم‌سازی داده با رعایت Informationssicherheit
  • پیاده‌سازی کار تیمی و حتی از راه دور با ابزارهای توسعه مناسب
  • تحویل محصول نهایی + مستندات کاربری (حتی به زبان خارجی)
  • بازنگری مناسب بودن ابزارها و کیفیت مستندات

🧩 منابع داده (Datenquellen)

  • پایگاه‌های داده رابطه‌ای (MySQL, PostgreSQL, SQL Server)
  • فایل‌ها (CSV, JSON, XML, Excel)
  • API / Webservices (REST, SOAP)
  • سیستم‌های سازمانی (ERP, CRM, Ticketsystem)
  • سنسورها و سیستم‌های IoT

قبل از استفاده باید: ساختار، حقوق دسترسی، مجوز قانونی (Datenschutz) و روش اتصال را بررسی کنی.

📐 از تحلیل تا پیاده‌سازی

  1. Anforderungsanalyse – نیاز مشتری چیست؟ کدام داده لازم است؟
  2. Quellen analysieren – ساختار، دسترسی، محدودیت حقوقی
  3. Konzept – چگونه داده را استخراج، تبدیل و ارائه می‌کنی؟ (ETL / API / DB-View)
  4. Informationssicherheit – رمزنگاری، احراز هویت، حداقل دسترسی
  5. Implementierung – پیاده‌سازی با ابزار مناسب (SQL, Python, Node, ...)
  6. Dokumentation & Übergabe – راهنمای استفاده برای مشتری
  7. Reflexion – آیا ابزار و کیفیت مستند کافی بود؟

🔐 Informationssicherheit و Datenschutz

  • فقط داده‌ای را بگیر که واقعاً لازم است (Datenminimierung)
  • دسترسی را محدود کن (Least Privilege)
  • انتقال امن (HTTPS, VPN, verschlüsselte Verbindungen)
  • رعایت DSGVO / GDPR در داده شخصی
  • لاگ و کنترل دسترسی در سیستم‌های حساس

کتاب IT-Grundschutz برای عمیق‌تر شدن در این بخش مفید است.

✏️ تمرین‌های عملی

تمرین ۱ – تحلیل منابع

مشتری می‌خواهد گزارش فروش از سه منبع داشته باشد: یک دیتابیس MySQL، یک فایل CSV هفتگی و یک API فروشگاه آنلاین. برای هر منبع بنویس: ساختار تقریبی، روش دسترسی، ریسک امنیتی.

تمرین ۲ – ER و SQL

برای یک سیستم تیکت ساده (User, Ticket, Kategorie, Kommentar) ER-Modell بکش و جداول را با کلید خارجی طراحی کن. یک Query با JOIN بنویس که تیکت‌های باز یک کاربر را نشان دهد.

تمرین ۳ – API

یک API ساده بساز که لیست تیکت‌ها را به صورت JSON برگرداند. آن را مستند کن و با curl یا Postman تست کن.

تمرین ۴ – تحویل به مشتری

برای همان API یک راهنمای کوتاه کاربری بنویس (به آلمانی یا انگلیسی): چطور صدا زده شود، چه فیلدهایی برمی‌گردد، چه خطایی ممکن است رخ دهد.

📖 اصطلاحات رسمی آلمانی

  • Datenquelle – منبع داده
  • Dezentral / Heterogen – غیرمتمرکز / ناهمگون
  • Zugriffsmöglichkeit / -mechanismus – امکان / سازوکار دسترسی
  • Informationssicherheit – امنیت اطلاعات
  • Rechtliche Rahmenbedingungen – چارچوب حقوقی
  • Bereitstellung – فراهم‌سازی
  • Entwicklungswerkzeug – ابزار توسعه
  • Dokumentation zur Handhabung – مستند کاربری
  • Arbeitsteilig / ortsunabhängig – کار تیمی / دورکاری
