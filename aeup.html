این درس چیست؟

داده از جاهای مختلف را بفهمی، بخوانی، ترکیب کنی و امن بدهی.

مثال: فروش در MySQL، انبار در CSV، سفارش آنلاین از API → یک گزارش واحد.

۱) منابع داده

  • پایگاه: جدول مشتریان MySQL
  • فایل: CSV حسابداری
  • API: JSON از فروشگاه

بپرس: داده شخصی؟ مجوز؟ تازگی داده؟

۲) ER و SQL

User(id,name) · Ticket(id,user_id,title,status)

SELECT t.title FROM Ticket t JOIN User u ON t.user_id=u.id WHERE u.name='Ali' AND t.status='open';

JOIN = چسباندن جداول با کلید مشترک.

۳) REST و JSON

  • GET = خواندن · POST = ایجاد
  • {"id":5,"title":"VPN down"}
  • 200 اوکی · 404 پیدا نشد · 401 بدون اجازه

۴) امنیت

  • HTTPS نه HTTP خام برای داده حساس
  • Least Privilege
  • DSGVO برای داده شخصی

۵) مستند تحویل

مثال: «GET /api/tickets?status=open با Bearer TOKEN → JSON آرایه»

What is this about?

Understand, read, combine and safely provide data from different sources.

Example: Sales in MySQL, warehouse CSV, shop API → one report.

1) Data sources

  • Database: MySQL customer table
  • File: accounting CSV
  • API: shop JSON

Ask: personal data? permission? freshness?

User(id,name) · Ticket(id,user_id,title,status)

SELECT t.title FROM Ticket t JOIN User u ON t.user_id=u.id WHERE u.name='Ali' AND t.status='open';

3) REST and JSON

  • GET = read · POST = create
  • {"id":5,"title":"VPN down"}

  • HTTPS not plain HTTP for sensitive data
