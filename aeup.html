AEuP – Daten systemübergreifend bereitstellen

Datenbanken · SQL · REST API · JSON · Integration

این درس چه چیزی است؟

داده‌ها را از منابع مختلف بخوانی، ترکیب کنی و به‌صورت امن در اختیار دیگر سیستم‌ها قرار دهی.

مثال: فروش در MySQL، انبار در فایل CSV، سفارش آنلاین از API → یک گزارش واحد

۱) منابع داده

  • پایگاه داده – جدول مشتریان در MySQL
  • فایل – CSV حسابداری یا Excel
  • API – داده JSON از فروشگاه آنلاین

همیشه بپرس: آیا داده شخصی است؟ مجوز داریم؟ داده تازه است؟

۲) مدل ER و SQL

مثال جداول:

User (id, name)
Ticket (id, user_id, title, status)

جمله SQL:

SELECT t.title
FROM Ticket t
JOIN User u ON t.user_id = u.id
WHERE u.name = 'Ali' AND t.status = 'open';

JOIN = چسباندن دو جدول با کلید مشترک

۳) REST API و JSON

  • GET = خواندن داده
  • POST = ایجاد داده جدید
  • PUT / PATCH = به‌روزرسانی
  • DELETE = حذف

مثال JSON: {"id": 5, "title": "VPN down"}

کدهای وضعیت: 200 = موفق، 404 = پیدا نشد، 401 = بدون مجوز

۴) فرمت‌های داده

  • JSON – سبک و معمول در API
  • CSV – ساده برای جدول
  • XML – قدیمی‌تر ولی هنوز استفاده می‌شود

۵) ETL (Extract, Transform, Load)

فرآیند یکپارچه‌سازی داده:

  1. Extract – بازیابی داده از منبع
  2. Transform – پاکسازی و تغییر فرمت
  3. Load – بارگذاری در سیستم مقصد

۶) امنیت داده

  • همیشه HTTPS استفاده کن (نه HTTP خام)
  • Least Privilege – فقط دسترسی لازم
  • DSGVO برای داده‌های شخصی
  • Authentication (API Key یا OAuth)
