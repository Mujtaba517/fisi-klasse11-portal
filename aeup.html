AEuP – داده و یکپارچه‌سازی

منبع داده · SQL · API · امنیت · با مثال + کوییز

این درس چیست؟

داده از جاهای مختلف می‌آید. تو باید بفهمی از کجاست، چطور بخوانی، ترکیب کنی و امن در اختیار بگذاری.

مثال: فروش در MySQL است، موجودی انبار در فایل CSV، سفارش‌های آنلاین از API فروشگاه. مدیر می‌خواهد یک گزارش واحد.

۱) انواع منبع داده با مثال

  • پایگاه داده: جدول مشتریان در MySQL
  • فایل: export روزانه Excel/CSV از حسابداری
  • API: GET https://shop.example/api/orders با JSON

قبل از اتصال بپرس: داده شخصی هست؟ مجوز داری؟ هر چند وقت یک‌بار عوض می‌شود؟

۲) ER و SQL خیلی ساده

مثال تیکت:

  • جدول User: id, name
  • جدول Ticket: id, user_id, title, status

برای دیدن تیکت‌های باز علی:

SELECT t.title FROM Ticket t JOIN User u ON t.user_id = u.id WHERE u.name = 'Ali' AND t.status = 'open';

JOIN یعنی دو جدول را با کلید مشترک به هم بچسبان.

۳) REST API با مثال

  • GET /tickets → لیست بخوان
  • POST /tickets → تیکت جدید بساز
  • پاسخ معمولاً JSON است: {"id":5,"title":"VPN down"}
  • کد 200 = اوکی · 404 = پیدا نشد · 401 = اجازه نداری

۴) امنیت داده با مثال

  • CSV شامل نام و IBAN را با HTTP خام روی اینترنت نفرست → HTTPS
  • کاربر پشتیبانی فقط تیکت ببیند نه حقوق همکاران → Least Privilege
  • داده شخصی = قوانین DSGVO

۵) تحویل به مشتری

مثال مستند یک‌خطی: «برای لیست تیکت‌های باز: GET /api/tickets?status=open با Header Authorization: Bearer TOKEN. پاسخ JSON آرایه است.»
