IT-Systeme (FU-IT)

IP · VLAN · DHCP · DNS · FA/DE/EN same topics

این درس چیست؟

شبکه را طراحی و راه بیندازی: IP، VLAN، DHCP، DNS، امنیت.

مثال: شرکت ۳۰ نفره، سه بخش → طرح، VLAN، DHCP، تست، مستند.

۱) OSI ساده

  • کابل؟ (L1)
  • لینک سوئیچ؟ (L2)
  • IP و Gateway؟ (L3)
  • برنامه/پورت؟ (L4–7)

مثال: Ping به Gateway اوکی، سایت باز نمی‌شود → اغلب DNS.

۲) IP و Gateway

  • PC: 192.168.10.50
  • Mask: 255.255.255.0
  • Gateway: 192.168.10.1

بدون Gateway فقط همان شبکه محلی.

۳) Subnetting

192.168.50.0/24 → دو /25: .0–.127 و .128–.255.

/26 ≈ ۶۲ host · /24 ≈ ۲۵۴ host

۴) VLAN

  • VLAN 10 اداری · 20 فنی · 30 مهمان
  • Access = یک VLAN برای PC
  • Trunk = چند VLAN به روتر

مثال: مهمان جدا از فایل‌سرور اداری.

۵) DHCP

DORA: Discover→Offer→Request→Ack. Pool مثلاً .100–.200، Gateway .1، DNS 8.8.8.8. سرور/پرینتر را exclude کن.

۶) DNS

files.firma.local → 192.168.10.10. اگر IP پینگ می‌شود ولی نام نه → DNS.

۷) امنیت

  • فقط پورت لازم
  • حداقل دسترسی
  • VLAN مهمان جدا
  • Backup و آپدیت

✅ کوییز

Worum geht es?

Netze planen und bereitstellen: IP, VLAN, DHCP, DNS, Sicherheit.

Beispiel: 30 Personen, 3 Abteilungen → Plan, VLAN, DHCP, Test, Doku.

1) OSI einfach

  • Kabel? (L1)
  • Switch-Link? (L2)
  • IP und Gateway? (L3)
  • Anwendung/Port? (L4–7)

Beispiel: Ping zum Gateway ok, Website nicht → oft DNS.

2) IP und Gateway

  • PC: 192.168.10.50
  • Maske: 255.255.255.0
  • Gateway: 192.168.10.1

Ohne Gateway nur lokales Netz.

3) Subnetting

192.168.50.0/24 → zwei /25: .0–.127 und .128–.255.

/26 ≈ 62 Hosts · /24 ≈ 254 Hosts

4) VLAN

  • VLAN 10 Büro · 20 Technik · 30 Gäste
  • Access = ein VLAN für PC
  • Trunk = mehrere VLANs zum Router

Beispiel: Gäste getrennt vom Büro-Fileserver.

5) DHCP

DORA: Discover→Offer→Request→Ack. Pool z. B. .100–.200, Gateway .1, DNS 8.8.8.8. Server/Drucker ausschließen.

6) DNS

files.firma.local → 192.168.10.10. IP pingt, Name nicht → DNS.

7) Sicherheit

  • Nur nötige Ports
  • Least Privilege
  • Gäste-VLAN getrennt
  • Backup und Updates

✅ Quiz

What is this about?

Design and run networks: IP, VLAN, DHCP, DNS, security.

Example: 30 staff, 3 departments → plan, VLAN, DHCP, test, document.

1) OSI simplified

  • Cable? (L1)
  • Switch link? (L2)
  • IP and gateway? (L3)
  • App/port? (L4–7)

Example: Gateway ping works, website does not → often DNS.

2) IP and gateway

  • PC: 192.168.10.50
  • Mask: 255.255.255.0
  • Gateway: 192.168.10.1

Without a gateway you only reach the local network.

3) Subnetting

192.168.50.0/24 → two /25s: .0–.127 and .128–.255.

/26 ≈ 62 hosts · /24 ≈ 254 hosts

4) VLAN

  • VLAN 10 office · 20 tech · 30 guest
  • Access = one VLAN for a PC
  • Trunk = many VLANs toward the router

Example: Guests isolated from the office file server.

5) DHCP

DORA: Discover→Offer→Request→Ack. Pool e.g. .100–.200, gateway .1, DNS 8.8.8.8. Exclude servers/printers.

6) DNS

files.firma.local → 192.168.10.10. IP pings but name fails → DNS.

7) Security

  • Only required ports
  • Least privilege
  • Separate guest VLAN
  • Backups and updates
