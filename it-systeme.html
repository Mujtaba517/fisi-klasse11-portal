IT-Systeme (FU-IT) – کامل

شبکه و سرویس‌ها با مثال ساده + کوییز پایانی

این درس چیست؟

یاد می‌گیری شبکه را طراحی و راه بیندازی: IP، VLAN، DHCP، DNS، امنیت.

مثال: شرکت ۳۰ نفره سه بخش دارد. تو طرح می‌کشی، VLAN می‌سازی، DHCP می‌دهی، تست می‌کنی و مستند می‌نویسی.

۱) OSI خیلی ساده

لایه‌ها مثل طبقات ساختمان‌اند. وقتی اینترنت قطع است از پایین به بالا چک کن:

  • کابل وصل است؟ (L1)
  • لینک روی سوئیچ سبز است؟ (L2)
  • IP و Gateway درست است؟ (L3)
  • پورت برنامه باز است؟ (L4–7)

مثال: Ping به Gateway جواب می‌دهد ولی سایت باز نمی‌شود → مشکل احتمالاً DNS است نه کابل.

۲) IP و Gateway با مثال

هر دستگاه در شبکه یک آدرس می‌خواهد.

  • PC: 192.168.10.50
  • Mask: 255.255.255.0 یعنی شبکه 192.168.10.x
  • Gateway: 192.168.10.1 (درِ خروجی به شبکه‌های دیگر / اینترنت)

بدون Gateway فقط با دستگاه‌های همان شبکه حرف می‌زنی.

۳) Subnetting با مثال عددی

شبکه بزرگ را تکه می‌کنی.

مثال: 192.168.50.0/24 را به دو نیم کن → دو شبکه /25:

  • اول: 192.168.50.0 تا .127 (Hosts: .1–.126)
  • دوم: 192.168.50.128 تا .255 (Hosts: .129–.254)

/26 ≈ ۶۲ host قابل استفاده · /24 ≈ ۲۵۴ host

۴) VLAN با مثال

روی یک سوئیچ فیزیکی، شبکه‌های جدا می‌سازی.

  • VLAN 10 = اداری · VLAN 20 = فنی · VLAN 30 = مهمان
  • پورت PC = Access یک VLAN
  • پورت به روتر = Trunk (چند VLAN)

مثال: مهمان نباید فایل سرور اداری را ببیند → VLAN جدا + قانون فایروال.

۵) DHCP با مثال

به‌جای تایپ دستی IP، سرور خودکار می‌دهد (DORA: Discover→Offer→Request→Ack).

مثال Pool: شبکه 192.168.10.0/24 · Gateway .1 · Range .100–.200 · DNS 8.8.8.8

آدرس پرینتر و سرور را از Pool خارج کن تا تداخل نشود.

۶) DNS با مثال

نام را به IP ترجمه می‌کند.

مثال: files.firma.local → 192.168.10.10

اگر IP را ping می‌کنی ولی نام کار نمی‌کند → مشکل DNS.

۷) امنیت ساده

  • فقط پورت لازم روی فایروال باز
  • رمز قوی + حداقل دسترسی
  • VLAN مهمان جدا
  • Backup و آپدیت
