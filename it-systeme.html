IT-Systeme (FU-IT)

Netzwerke planen und bereitstellen · IP · VLAN · DHCP · DNS · Sicherheit

موضوعات: ۱) مدل OSI ۲) آدرس‌دهی IP و Gateway ۳) Subnetting ۴) VLAN ۵) DHCP ۶) DNS ۷) Routing پایه ۸) NAT ۹) IPv6 ۱۰) توپولوژی شبکه ۱۱) عیب‌یابی ۱۲) امنیت پایه

این درس چیست؟

شبکه‌های کامپیوتری را طراحی، پیاده‌سازی و مدیریت کنید.

مثال واقعی: شرکتی با ۳۰ کارمند، ۳ بخش (اداری، فنی، مهمان). باید VLAN، DHCP، DNS و امنیت داشته باشد.

۱) مدل OSI (ساده‌شده)

  • L1 فیزیکی: کابل، سوئیچ، نور
  • L2 لینک دیتا: MAC، Switch، VLAN
  • L3 شبکه: IP، Gateway، Router
  • L4–7: TCP/UDP، پورت، برنامه‌ها

مثال: Ping به Gateway کار می‌کند ولی سایت باز نمی‌شود → اغلب مشکل در DNS یا Firewall است.

۲) آدرس‌دهی IP و Gateway

  • IP کامپیوتر: 192.168.10.50
  • Subnet Mask: 255.255.255.0 (/24)
  • Gateway: 192.168.10.1 (معمولاً روتر)

بدون Gateway فقط همان شبکه محلی قابل دسترس است.

۳) Subnetting

192.168.50.0/24 را به دو شبکه /25 تقسیم کنید:

  • شبکه ۱: 192.168.50.0 – 192.168.50.127
  • شبکه ۲: 192.168.50.128 – 192.168.50.255

/24 ≈ 254 Host  |  /26 ≈ 62 Host  |  /27 ≈ 30 Host

۴) VLAN (Virtual LAN)

  • VLAN 10 = اداری
  • VLAN 20 = فنی
  • VLAN 30 = مهمان (Guest)

Access Port: یک VLAN برای کامپیوتر
Trunk Port: چند VLAN بین سوئیچ و روتر

مثال: مهمان نمی‌تواند به File Server اداری دسترسی داشته باشد.

۵) DHCP

فرآیند DORA:

  1. Discover – کلاینت دنبال سرور می‌گردد
  2. Offer – سرور IP پیشنهاد می‌کند
  3. Request – کلاینت قبول می‌کند
  4. Ack – سرور تأیید می‌کند

مثال Pool: 192.168.10.100 – 192.168.10.200
Gateway: .1   DNS: 8.8.8.8 یا سرور داخلی

۶) DNS

تبدیل نام به IP:

fileserver.firma.local → 192.168.10.10

مشکل معمول: IP پینگ می‌شود ولی نام باز نمی‌شود → مشکل DNS.

۷) Routing پایه

روتر تصمیم می‌گیرد پکت به کجا برود.

  • Static Route – مسیر دستی تعریف می‌شود
  • Default Gateway – مسیر پیش‌فرض برای خروج به اینترنت

مثال: اگر کامپیوتر در VLAN 10 باشد و بخواهد به VLAN 20 برسد، روتر باید مسیر داشته باشد.

۸) NAT (Network Address Translation)

تبدیل آدرس خصوصی به آدرس عمومی برای خروج به اینترنت.

مثال: کامپیوتر با 192.168.10.50 به اینترنت می‌رود. روتر آدرس را به 203.0.113.5 تبدیل می‌کند.

۹) IPv6

نسخه جدید IP با آدرس طولانی‌تر (۱۲۸ بیت).

مثال: 2001:0db8:85a3::8a2e:0370:7334

در بسیاری شرکت‌ها هنوز IPv4 استفاده می‌شود، اما IPv6 آینده است.

۱۰) توپولوژی شبکه

  • Star – همه به یک سوئیچ مرکزی
  • Bus – همه روی یک کابل
  • Mesh – هر دستگاه به چند دستگاه دیگر

شرکت‌ها معمولاً از Star استفاده می‌کنند.

۱۱) عیب‌یابی شبکه

  1. کابل و لینک فیزیکی را چک کن (L1)
  2. ipconfig / ip addr – IP داری؟
  3. Ping به Gateway
  4. Ping به ۸.۸.۸.۸
  5. DNS را تست کن (nslookup)

مثال: اگر Gateway پینگ می‌شود ولی اینترنت نه → مشکل در DNS یا Firewall.

۱۲) امنیت پایه

  • فقط پورت‌های لازم باز باشد
  • Least Privilege (حداقل دسترسی)
  • VLAN مهمان جدا
  • Backup و Update منظم
  • Firewall بین VLAN‌ها

✅ کوییز

Worum geht es?

Computernetzwerke planen, einrichten und verwalten.

Beispiel: Firma mit 30 Mitarbeitern, 3 Abteilungen. Benötigt VLANs, DHCP, DNS und Sicherheit.

1) OSI-Modell (vereinfacht)

  • L1 Physical: Kabel, Switch, Licht
  • L2 Data Link: MAC, Switch, VLAN
  • L3 Network: IP, Gateway, Router
  • L4–7: TCP/UDP, Ports, Anwendungen

Beispiel: Ping zum Gateway funktioniert, Website nicht → meist DNS oder Firewall.

2) IP-Adressierung und Gateway

  • PC-IP: 192.168.10.50
  • Subnet Mask: 255.255.255.0 (/24)
  • Gateway: 192.168.10.1 (meist Router)

Ohne Gateway nur das lokale Netz erreichbar.

3) Subnetting

192.168.50.0/24 in zwei /25-Netze aufteilen:

  • Netz 1: 192.168.50.0 – 192.168.50.127
  • Netz 2: 192.168.50.128 – 192.168.50.255

/24 ≈ 254 Hosts  |  /26 ≈ 62 Hosts  |  /27 ≈ 30 Hosts

4) VLAN

  • VLAN 10 = Büro
  • VLAN 20 = Technik
  • VLAN 30 = Gäste

Access-Port: ein VLAN für den PC
Trunk-Port: mehrere VLANs zwischen Switch und Router

Beispiel: Gäste dürfen nicht auf den Büro-Fileserver zugreifen.

5) DHCP

Prozess DORA:

  1. Discover
  2. Offer
  3. Request
  4. Acknowledge

Beispiel Pool: 192.168.10.100 – 192.168.10.200
Gateway: .1   DNS: 8.8.8.8 oder interner Server

6) DNS

Name zu IP auflösen:

fileserver.firma.local → 192.168.10.10

Typisches Problem: IP pingt, Name funktioniert nicht → DNS-Problem.

7) Routing

Router entscheidet, wohin Pakete gehen. Static Route oder Default Gateway.

8) NAT

Übersetzt private IPs in eine öffentliche IP für den Internetzugang.

9) IPv6

Neue IP-Version mit längeren Adressen (128 Bit).

10) Topologien

Star, Bus, Mesh. Unternehmen nutzen meist Stern-Topologie.

11) Fehlersuche

  1. Kabel prüfen
  2. IP prüfen
  3. Gateway pingen
  4. DNS testen

12) Sicherheit

  • Nur notwendige Ports öffnen
  • Least Privilege
  • Gäste-VLAN getrennt
  • Regelmäßiges Backup und Updates
  • Firewall zwischen VLANs

✅ Quiz

What is this about?

Plan, set up and manage computer networks.

Example: Company with 30 employees, 3 departments. Needs VLANs, DHCP, DNS and security.

1) OSI Model (simplified)

  • L1 Physical: Cable, switch, light
  • L2 Data Link: MAC, Switch, VLAN
  • L3 Network: IP, Gateway, Router
  • L4–7: TCP/UDP, ports, applications

Example: Gateway ping works, website does not → usually DNS or firewall.

2) IP Addressing and Gateway

  • PC IP: 192.168.10.50
  • Subnet Mask: 255.255.255.0 (/24)
  • Gateway: 192.168.10.1 (usually router)

Without a gateway you can only reach the local network.

3) Subnetting

Split 192.168.50.0/24 into two /25 networks:

  • Network 1: 192.168.50.0 – 192.168.50.127
  • Network 2: 192.168.50.128 – 192.168.50.255

/24 ≈ 254 hosts  |  /26 ≈ 62 hosts  |  /27 ≈ 30 hosts

4) VLAN

  • VLAN 10 = Office
  • VLAN 20 = Technical
  • VLAN 30 = Guest

Access Port: one VLAN for the PC
Trunk Port: multiple VLANs between switch and router

Example: Guests must not access the office file server.

5) DHCP

DORA process:

  1. Discover
  2. Offer
  3. Request
  4. Acknowledge

Example pool: 192.168.10.100 – 192.168.10.200
Gateway: .1   DNS: 8.8.8.8 or internal server

6) DNS

Resolve name to IP:

fileserver.firma.local → 192.168.10.10

Common problem: IP pings but name does not work → DNS issue.

7) Basic Routing

The router decides where packets go. Static route or default gateway.

8) NAT

Translates private IPs to a public IP for internet access.

9) IPv6

Newer IP version with longer addresses (128 bit).

10) Network Topologies

Star, Bus, Mesh. Companies usually use star topology.

11) Troubleshooting

  1. Check cable
  2. Check IP
  3. Ping gateway
  4. Test DNS

12) Security Basics

  • Open only necessary ports
  • Least privilege
  • Separate guest VLAN
  • Regular backups and updates
  • Firewall between VLANs
