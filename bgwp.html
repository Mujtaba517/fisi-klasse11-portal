BGWP – Betriebswirtschaftliche Prozesse

Serviceanfragen bearbeiten · SLA · ITIL · Incident Management

این درس چه چیزی است؟

درخواست‌های کاربران را به‌درستی ثبت، اولویت‌بندی، حل یا Escalate کنی و مستند کنی.

مثال واقعی: «پرینتر طبقه ۲ کار نمی‌کند و باید فاکتور چاپ کنم.»

۱) Serviceanfrage (درخواست خدمات)

هر درخواستی که کاربر از IT دارد:

  • خرابی (پرینتر کار نمی‌کند)
  • نصب نرم‌افزار
  • دسترسی جدید
  • سؤال ساده

مثال: «رمز را فراموش کردم» → Serviceanfrage ساده
«اینترنت کل شرکت قطع شده» → Incident با اولویت بالا

۲) فرآیند استاندارد پردازش تیکت

  1. Aufnahme – کی؟ چه مشکلی؟ از کی شروع شده؟
  2. SLA – چقدر وقت داریم؟
  3. دسته‌بندی – سخت‌افزار / نرم‌افزار / شبکه / دسترسی
  4. اولویت – شدت + فوریت
  5. حل یا Eskalation
  6. مستند و بستن

۳) SLA (Service Level Agreement)

قول کتبی درباره زمان خدمات:

  • Reaktionszeit = زمان اولین پاسخ (مثلاً ۳۰ دقیقه)
  • Lösungszeit = زمان حل کامل (مثلاً ۴ ساعت)

مثال: تیکت ساعت ۱۰:۰۰ ثبت شد → باید تا ۱۰:۳۰ پاسخ داده باشد. اگر ساعت ۱۰:۳۵ هنوز پاسخ نداده باشی → نقض SLA.

۴) سطوح پشتیبانی (Support Levels)

  • 1st Level – ثبت تیکت، راهنمایی ساده، ریست رمز
  • 2nd Level – مشکلات سرور و شبکه پیچیده
  • 3rd Level – سازنده نرم‌افزار/سخت‌افزار

۵) Incident در مقابل Problem

  • Incident = الان چیزی خراب است → سریع برگردان
  • Problem = علت ریشه‌ای که باعث تکرار می‌شود

مثال: ریستارت پرینتر = Incident
درایور قدیمی که همیشه مشکل ایجاد می‌کند = Problem

۶) اولویت‌بندی

  • ایمیل کل شرکت قطع → Kritisch
  • یک بخش نمی‌تواند فاکتور بزند → Hoch
  • ماوس جدید برای یک نفر → Niedrig

۷) Deeskalation (آرام کردن کاربر)

همیشه آرام بمان. اول همدردی کن، بعد سؤال فنی بپرس.

مثال جمله خوب: «متوجه هستم که عصبانی‌اید. بیایید قدم به قدم چک کنیم.»

✅ کوییز

Worum geht es?

Serviceanfragen richtig aufnehmen, priorisieren, lösen oder eskalieren und dokumentieren.

1) Serviceanfrage

Jede Anfrage an die IT: Störung, Installation, Zugriff, Frage.

2) Standardprozess

Aufnahme → SLA → Klassifizierung → Priorisierung → Lösung/Eskalation → Dokumentation

3) SLA

Reaktionszeit und Lösungszeit sind vertraglich festgelegt.

4) Support-Level

1st Level (Standard), 2nd Level (komplex), 3rd Level (Hersteller)

5) Incident vs. Problem

Incident = aktuelle Störung. Problem = Ursache wiederkehrender Störungen.

✅ Quiz

What is this about?

Correctly capture, prioritise, resolve or escalate service requests and document them.

1) Service Request

Any request to IT: outage, installation, access, question.

2) Standard Process

Capture → SLA → Classify → Prioritise → Solve/Escalate → Document

3) SLA

Response time and resolution time are contractually defined.

4) Support Levels

1st Level (standard), 2nd Level (complex), 3rd Level (vendor)

5) Incident vs Problem

Incident = current disruption. Problem = root cause of recurring issues.
