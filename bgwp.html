BGWP – کامل برای امتحان

Serviceanfragen · SLA · ITIL پایه · با مثال و کوییز پایانی

این درس درباره چیست؟

یاد می‌گیری وقتی کاربر مشکل دارد، چطور درست تیکت بگیری، اولویت بدهی، حل کنی یا به سطح بالاتر بفرستی و همه را مستند کنی.

مثال واقعی: خانم احمدی زنگ می‌زند: «پرینتر طبقه ۲ کار نمی‌کند و باید فاکتور چاپ کنم.» تو باید سؤال بپرسی، تیکت باز کنی، اولویت بگذاری و یا خودت حل کنی یا Escalate کنی.

۱) Serviceanfrage چیست؟

هر درخواستی که کاربر از IT می‌خواهد: خرابی، نصب برنامه، دسترسی، سؤال.

مثال:

  • «رمز عبور را فراموش کردم» → Serviceanfrage
  • «اینترنت کل شرکت قطع است» → هم Serviceanfrage است هم اغلب Incident با اولویت بالا

۲) فرآیند استاندارد (گام‌به‌گام)

  1. Aufnahme – نام کاربر، شماره داخلی، چه چیزی خراب است، از کی؟
  2. SLA – چقدر وقت برای جواب داری؟
  3. دسته‌بندی – سخت‌افزار / نرم‌افزار / شبکه / دسترسی
  4. اولویت – چقدر بد است و چقدر فوری؟
  5. حل یا Eskalation
  6. مستند و بستن تیکت

مثال: کاربر نمی‌تواند به SharePoint برود. سؤال: از خانه است یا دفتر؟ VPN وصل است؟ مرورگر چیست؟ پیام خطا چیست؟ → اگر VPN مشکل است و تو First Level هستی، راهنمایی می‌کنی؛ اگر سرور خراب است → Escalate.

۳) SLA به زبان ساده

SLA = قول کتبی شرکت به مشتری درباره زمان خدمت.

  • Reaktionszeit = حداکثر زمان اولین پاسخ (مثلاً ۳۰ دقیقه)
  • Lösungszeit = حداکثر زمان حل (مثلاً ۴ ساعت)

مثال: SLA می‌گوید اولویت بالا ۳۰ دقیقه واکنش. تیکت ۱۰:۰۰ ثبت شد. ساعت ۱۰:۳۵ هنوز کسی جواب نداده → SLA نقض شده؛ باید فوری رسیدگی و گزارش کنی.

۴) Support-Level

  • 1st Level – خط اول: ثبت، راهنمای ساده، ریست رمز
  • 2nd Level – متخصص‌تر: سرور، شبکه پیچیده
  • 3rd Level – سازنده نرم‌افزار / سخت‌افزار

مثال: Outlook باز نمی‌شود. ۱) Outlook را Repair می‌کنی (1st). ۲) نشد → پروفایل خراب، به 2nd می‌فرستی با لاگ. ۳) باگ نرم‌افزار مایکروسافت → 3rd.

۵) Incident در مقابل Problem

  • Incident = الان سرویس خراب است → سریع برگردان
  • Problem = چرا چند بار خراب شد؟ علت ریشه‌ای

مثال: پرینتر امروز ۳ بار Hang کرد. هر بار Restart = حل Incident. بررسی می‌کنی درایور قدیمی است = کار روی Problem.

۶) اولویت با مثال

  • کل ایمیل شرکت قطع → Kritisch
  • یک بخش نمی‌تواند فاکتور بزند → Hoch
  • یک نفر ماوس جدید می‌خواهد → Niedrig

۷) Deeskalation (آرام کردن کاربر)

کاربر عصبانی است. تو نباید عصبانی شوی.

مثال جمله: «متوجه می‌شوم چقدر اذیت‌کننده است. الان با هم قدم‌به‌قدم چک می‌کنیم تا دوباره کار کند.» بعد سؤال فنی بپرس.

✅ کوییز BGWP – خودت را تست کن

قبل از ثبت می‌توانی جواب را عوض کنی.

Worum geht es?

Tickets aufnehmen, priorisieren, lösen oder eskalieren und dokumentieren.

Beispiel: Nutzerin: Drucker 2. OG defekt, Rechnung muss gedruckt werden → Fragen, Ticket, Prio, lösen oder eskalieren.

Kernpunkte

  • Prozess: Aufnahme → SLA → Klasse → Prio → Lösung/Eskalation → Doku
  • SLA = Reaktions- und Lösungszeit
  • 1st / 2nd / 3rd Level
  • Incident = Störung jetzt · Problem = Ursache
  • Ruhig bleiben (Deeskalation)

✅ Quiz BGWP

What is this about?

Take tickets, prioritise, fix or escalate, and document.

Example: Printer on floor 2 is down and invoices must be printed → ask, log, prioritise, solve or escalate.

Key points

  • Process: capture → SLA → classify → priority → solve/escalate → document
  • SLA = response and resolution times
  • Support levels 1 / 2 / 3
  • Incident = outage now · Problem = root cause
  • Stay calm (de-escalation)
