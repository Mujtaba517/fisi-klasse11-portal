Fachpraxis IT Plus – شبکه عملی

Switch · Router · IP · DHCP · VLAN – کانفیگ واقعی برای کلاس و Packet Tracer

🎯 آنچه در Fp-Plus تمرین می‌کنید

پیکربندی عملی شبکه: آدرس‌دهی IP، سوئیچ، روتر، DHCP و ارتباط بین شبکه‌ها.
  • تنظیم IP روی کلاینت و رابط روتر
  • VLAN روی سوئیچ (Access / Trunk)
  • Inter-VLAN Routing (Router-on-a-Stick یا L3)
  • DHCP Server برای دادن خودکار IP
  • تست با ping و عیب‌یابی

1️⃣ طرح IP نمونه آزمایشگاه

  • VLAN 10 (Büro): 192.168.10.0/24 · Gateway .1 · DHCP .100–.200
  • VLAN 20 (Technik): 192.168.20.0/24 · Gateway .1 · DHCP .100–.200
  • VLAN 30 (Gäste): 192.168.30.0/24 · Gateway .1

روی روتر هر VLAN یک Subinterface با همان Gateway می‌گیرد.

2️⃣ سوئیچ – VLAN و پورت‌ها (Cisco-Style)

enable
configure terminal
vlan 10
 name BUERO
vlan 20
 name TECHNIK
vlan 30
 name GAST
exit

interface fa0/1
 switchport mode access
 switchport access vlan 10
interface fa0/2
 switchport mode access
 switchport access vlan 20
interface fa0/24
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30
end
write memory

Access = یک VLAN برای PC · Trunk = چند VLAN به سمت روتر/سوئیچ دیگر

3️⃣ روتر – Subinterface (Router-on-a-Stick)

enable
configure terminal
interface g0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
interface g0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
interface g0/0.30
 encapsulation dot1Q 30
 ip address 192.168.30.1 255.255.255.0
interface g0/0
 no shutdown
end
write memory

کابل Trunk از سوئیچ به همین پورت فیزیکی روتر وصل می‌شود.

4️⃣ DHCP روی روتر

configure terminal
ip dhcp excluded-address 192.168.10.1 192.168.10.99
ip dhcp pool BUERO
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 dns-server 8.8.8.8

ip dhcp excluded-address 192.168.20.1 192.168.20.99
ip dhcp pool TECHNIK
 network 192.168.20.0 255.255.255.0
 default-router 192.168.20.1
 dns-server 8.8.8.8
end

آدرس‌های Gateway و سرورها را از Pool خارج کن (excluded).

5️⃣ IP روی کلاینت (ویندوز)

  • خودکار (DHCP): تنظیمات شبکه → IPv4 → خودکار
  • دستی: مثلاً 192.168.10.50 · Mask 255.255.255.0 · Gateway 192.168.10.1 · DNS 8.8.8.8

تست: ipconfig /all · ping 192.168.10.1 · ping 192.168.20.1

6️⃣ ترتیب کار در کلاس / Packet Tracer

  1. توپولوژی بکش: ۱ روتر، ۱ سوئیچ، حداقل ۲ PC
  2. VLANها روی سوئیچ بساز و پورت‌ها را Access/Trunk کن
  3. Subinterface + IP روی روتر
  4. DHCP Poolها
  5. PCها را به DHCP بگذار و IP بگیر
  6. Ping داخل VLAN و بین VLAN
  7. جدول IP و دستورات را مستند کن

7️⃣ عیب‌یابی سریع

  • IP نگرفت؟ Trunk، encapsulation dot1Q، DHCP pool و excluded را چک کن
  • داخل VLAN ping می‌شود بین VLAN نه؟ Routing/Subinterface
  • show vlan brief · show ip interface brief · show ip dhcp binding

✏️ تمرین‌های Fp-Plus

۱

سناریوی بالا را در Packet Tracer پیاده کن و اسکرین از IP هر PC بگیر.
