Fachpraxis

Switch · Router · DHCP · FA/DE/EN same topics

هدف

VLAN، روتر، DHCP و ping را خودت در Packet Tracer یا آزمایشگاه پیاده کنی.

۱) سناریو

  • VLAN 10: 192.168.10.0/24 · GW .1
  • VLAN 20: 192.168.20.0/24 · GW .1
  • ۱ سوئیچ · ۱ روتر · ۲ PC

۲) سوئیچ

vlan 10
 name BUERO
vlan 20
 name TECHNIK
interface fa0/1
 switchport mode access
 switchport access vlan 10
interface fa0/2
 switchport mode access
 switchport access vlan 20
interface fa0/24
 switchport mode trunk

Access برای PC · Trunk به روتر.

۳) روتر

interface g0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
interface g0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
interface g0/0
 no shutdown

۴) DHCP

ip dhcp excluded-address 192.168.10.1 192.168.10.99
ip dhcp pool BUERO
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 dns-server 8.8.8.8

۵) تست

  1. ipconfig → IP درست؟
  2. ping Gateway
  3. ping VLAN دیگر
