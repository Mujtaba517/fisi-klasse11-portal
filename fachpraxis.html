Fachpraxis – کانفیگ شبکه کامل

Switch · Router · IP · DHCP · VLAN با مثال دستوری + کوییز

هدف کلاس عملی

خودت بتوانی در Packet Tracer یا آزمایشگاه: VLAN بسازی، روتر را وصل کنی، DHCP بدهی و با ping ثابت کنی که کار می‌کند.

۱) سناریوی نمونه (از اول تا آخر)

یک شرکت کوچک: اداری و فنی جدا باشند.

  • VLAN 10 Büro: شبکه 192.168.10.0/24 · Gateway .1
  • VLAN 20 Technik: شبکه 192.168.20.0/24 · Gateway .1
  • ۱ سوئیچ · ۱ روتر · ۲ کامپیوتر

۲) سوئیچ – مثال دستور

اول VLAN بساز، بعد بگو هر پورت مال کدام VLAN است.

vlan 10
 name BUERO
vlan 20
 name TECHNIK
interface fa0/1
 switchport mode access
 switchport access vlan 10
interface fa0/2
 switchport mode access
 switchport access vlan 20
interface fa0/24
 switchport mode trunk

مثال: PC اداری به fa0/1 · PC فنی به fa0/2 · کابل به روتر روی fa0/24 (Trunk).

۳) روتر – مثال Subinterface

یک کابل فیزیکی، چند شبکه منطقی (Router-on-a-Stick).

interface g0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
interface g0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
interface g0/0
 no shutdown

مثال: حالا PC در VLAN10 می‌تواند به Gateway 192.168.10.1 برسد و از آنجا به VLAN20 برود.

۴) DHCP – مثال Pool

ip dhcp excluded-address 192.168.10.1 192.168.10.99
ip dhcp pool BUERO
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 dns-server 8.8.8.8

مثال: PC را روی DHCP بگذار → باید چیزی مثل 192.168.10.100 بگیرد و Gateway .1 باشد.

۵) تست – چه چیزی باید سبز شود؟

  1. ipconfig روی PC → IP درست؟
  2. ping 192.168.10.1 → Gateway؟
  3. ping 192.168.20.x → VLAN دیگر؟

اگر ۱ و ۲ اوکی ولی ۳ نه → Routing/Subinterface را چک کن.
