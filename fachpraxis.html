🎯 چرا Fachpraxis برای IHK مهم است؟

امتحان و شغل FISI عملی است: نصب، پیکربندی، تست، عیب‌یابی و مستند. نظریه بدون دست، کافی نیست.

در AP Teil 2 بعداً پروژه عملی بزرگ داری. عادت مستندسازی و کار تمیز از همین حالا امتیاز است.

🧰 مهارت‌های ضروری آزمایشگاه

  • نصب ویندوز / لینوکس روی سخت‌افزار یا VM
  • شبکه پایه: IP ثابت، Gateway، DNS، Ping، Traceroute
  • VirtualBox/VMware: Host-Only / NAT / Bridged
  • Packet Tracer: VLAN، Router-on-a-Stick، DHCP
  • کاربر و دسترسی: Local / AD مقدماتی / Linux users & chmod پایه
  • Share فایل: SMB یا NFS
  • Backup ساده و بازیابی آزمایشی

📝 استاندارد مستند پروژه (برای نمره)

  1. عنوان، هدف، محدوده (Scope)
  2. نیاز مشتری / فرض‌ها
  3. طرح فنی (توپولوژی، IP، سرویس‌ها)
  4. مراحل اجرا
  5. تست‌ها و نتایج
  6. مشکلات و راه‌حل‌ها
  7. ارزیابی و پیشنهاد بهبود

🚀 پروژه‌های پیشنهادی صنف ۱۱

A – آزمایشگاه شبکه

۳ VLAN + DHCP + Inter-VLAN + مستند جدول IP.

B – فایل سرور

لینوکس Samba + گروه کاربری + اتصال از ویندوز + Backup.

C – CPS کوچک

ESP32 دما → MQTT → Node-RED آلارم + پروتکل تست.

D – میز کار IT

یک VM کلاینت استاندارد: آپدیت، آنتی‌ویروس مفهومی، کاربر محدود، مستند تحویل به «مشتری».
