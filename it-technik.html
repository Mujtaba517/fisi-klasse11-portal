IT-Technik – Cyber-physische Systeme

CPS · Sensoren · ESP32 · MQTT · IoT

این درس چه چیزی است؟

دنیای فیزیکی را به دنیای IT وصل کنید (Cyber-Physical Systems).

مثال ساده: ترموستات هوشمند = سنسور دما + وای‌فای + اپ موبایل

۱) اجزای یک سیستم CPS

  • Sensor – مقدار فیزیکی را می‌خواند (مثل DHT22 برای دما و رطوبت)
  • Controller – مغز سیستم (مثل ESP32)
  • Netzwerk – وای‌فای یا اترنت + MQTT
  • IT-System – نمایش، ذخیره، آلارم (مثل Node-RED)
  • Aktor – چیزی را حرکت می‌دهد (رله، فن، موتور)

۲) MQTT چیست؟

پروتکل سبک برای ارسال پیام بین دستگاه‌ها.

  • Publish – فرستادن پیام روی یک Topic (مثل lager/temp)
  • Subscribe – دریافت پیام‌های یک Topic
  • Broker – واسط مرکزی (مثل Mosquitto)
  • QoS 0 – ممکن است پیام گم شود
  • QoS 1 – حداقل یک بار تحویل داده می‌شود

۳) مثال کامل: نظارت بر سردخانه

  1. سنسور دما را می‌خواند
  2. ESP32 اطلاعات را با MQTT می‌فرستد
  3. Node-RED دما را نمایش می‌دهد و ذخیره می‌کند
  4. اگر دما بالا رفت → پیام به مسئول ارسال می‌شود

۴) ایمنی

  • Betriebssicherheit – ولتاژ مناسب، دکمه قطع اضطراری
  • Datensicherheit – MQTT بدون رمز روی اینترنت خطرناک است

✅ کوییز

Worum geht es?

Die physische Welt mit der IT verbinden (Cyber-physische Systeme).

1) Komponenten eines CPS

Sensor → Controller (ESP32) → Netzwerk (MQTT) → IT-System → Aktor

2) MQTT

Publish / Subscribe über einen Broker. QoS 0 oder QoS 1.

3) Beispiel Kühlraum

Temperatursensor → ESP32 → MQTT → Alarm bei zu hoher Temperatur

What is this about?

Connect the physical world to IT (Cyber-Physical Systems).

1) Components of a CPS

Sensor → Controller (ESP32) → Network (MQTT) → IT system → Actuator

2) MQTT

Publish / Subscribe via a broker. QoS 0 or QoS 1.

3) Cold storage example

Temperature sensor → ESP32 → MQTT → alarm if temperature too high
