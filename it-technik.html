IT-Technik

CPS · MQTT · FA/DE/EN same topics

این درس چیست؟

دنیای فیزیکی را به IT وصل کن (CPS).

مثال: ترموستات هوشمند = سنسور + وای‌فای + اپ.

۱) اجزا

  • Sensor: DHT22 دما
  • Controller: ESP32
  • Netzwerk: WLAN + MQTT
  • IT: Node-RED آلارم
  • Aktor: رله فن

۲) MQTT

  • Publish روی lager/temp
  • Subscribe در Node-RED
  • Broker = واسط (Mosquitto)
  • QoS 0 ممکن است گم شود · QoS 1 حداقل یک‌بار

۳) مثال سردخانه

  1. سنسور اندازه می‌گیرد
  2. ESP32 با MQTT می‌فرستد
  3. نمایش و ذخیره
  4. دما بالا → پیام به مسئول

۴) ایمنی

  • Betriebssicherheit: ولتاژ، قطع اضطراری
  • Datensicherheit: MQTT بدون رمز روی اینترنت عمومی خطرناک

✅ کوییز

Worum geht es?

Physische Welt mit IT verbinden (CPS).

Beispiel: Smart-Thermostat = Sensor + WLAN + App.

1) Komponenten

  • Sensor: DHT22 Temperatur
  • Controller: ESP32
  • Netzwerk: WLAN + MQTT
  • IT: Node-RED Alarm
  • Aktor: Relais/Lüfter

2) MQTT

  • Publish auf lager/temp
  • Subscribe in Node-RED
  • Broker = Vermittler (Mosquitto)
  • QoS 0 kann verloren gehen · QoS 1 mindestens einmal

3) Beispiel Kühlraum

  1. Sensor misst
  2. ESP32 sendet per MQTT
  3. Anzeige und Speicherung
  4. Temperatur hoch → Nachricht an Verantwortlichen

4) Sicherheit

  • Betriebssicherheit: Spannung, Not-Aus
  • Datensicherheit: MQTT ohne Schutz im öffentlichen Netz riskant

✅ Quiz

What is this about?

Connect the physical world to IT (CPS).

Example: Smart thermostat = sensor + Wi-Fi + app.

1) Components

  • Sensor: DHT22 temperature
  • Controller: ESP32
  • Network: WLAN + MQTT
  • IT: Node-RED alarm
  • Actuator: relay/fan

2) MQTT

  • Publish on lager/temp
  • Subscribe in Node-RED
  • Broker = intermediary (Mosquitto)
  • QoS 0 may be lost · QoS 1 at least once

3) Cold-storage example

  1. Sensor measures
  2. ESP32 sends via MQTT
  3. Display and store
  4. High temperature → message to the person in charge

4) Safety

  • Operational safety: voltage, emergency stop
  • Data safety: plain MQTT on the public internet is risky
