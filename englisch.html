Machine Languages & Programming Languages

  • Machine Code / Machine Language: زبان ماشین – مستقیم برای پردازنده
  • Assembly Language: زبان سطح پایین با استفاده از منمونیک
  • Mnemonic: مخفف برای دستورات (مثل AND، SUB، MUL)
  • High-level languages: زبان‌های سطح بالا (قابل فهم‌تر برای انسان)

زبان ماشین مستقیم اجرا می‌شود اما سخت و وابسته به ماشین است. زبان‌های سطح بالا باید به زبان ماشین ترجمه (compile) شوند.

واژگان مهم (Vocabulary)

  • mnemonic – مخفف / Eselsbrücke
  • to assemble – مونتاژ کردن / جمع کردن
  • to compile – ترجمه / کامپایل کردن
  • machine dependent – وابسته به ماشین
  • tedious – خسته‌کننده / کسل‌کننده
  • instruction – دستور
  • executables – فایل‌های قابل اجرا
  • payroll program – برنامه حقوق و دستمزد

Machine Languages

Machine code is directly executable by the processor but tedious and machine-dependent.
Assembly language uses mnemonics (e.g. AND, SUB, MUL).
High-level languages must be compiled.

Key Vocabulary

mnemonic = memory aid / abbreviation
to assemble = to put together
to compile = to translate into machine code
machine dependent = dependent on the hardware
tedious = boring / laborious
instruction = command
executables = programs that can be run
